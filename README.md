# 🗾「リスナーと作る！全国観光マップ（フロリの47都道府県パタパタ旅行企画）」

47都道府県の観光地・ご当地グルメ・お酒・リスナー口コミデータをインタラクティブに閲覧・探索できるWeb地図（`index.html`）の自動生成ツールです。

- 🌐 **本番公開URL**: [https://mitchy-ym.github.io/patapata_travel_map_maker/](https://mitchy-ym.github.io/patapata_travel_map_maker/)
- 📦 **GitHub リポジトリ**: [https://github.com/mitchy-ym/patapata_travel_map_maker](https://github.com/mitchy-ym/patapata_travel_map_maker)

---

## 🌟 主な機能と特徴

1. **🗺️ / 🔍 デュアルアクション連携（全47都道府県）**:
   - **📸 観光地・名所**: すべてのスポットに `[🗺️ Googleマップ]` と `[🔍 Google検索]` の両方のアクションボタンを搭載（※スラングや概念等は検索のみに最適化）。
   - **🍽️ ご当地グルメ・食べ物**: 特定の店舗・施設・市場が存在する名物には `[🗺️]` と `[🔍]` の両方を、一般的な郷土料理には `[🔍]` を最適配置。
   - **🍶 地酒・お酒**: すべての銘酒・お酒に `[🔍 Google検索]` を配置。

2. **💬 リスナーおすすめメモ（吹き出しトグル）＆ ✏️ 口コミ投稿機能**:
   - 各スポットの横にある **`[💬]`** ボタンを押すと、その場所に関するリスナーのおすすめ情報・アドバイスがふんわり吹き出しで展開。
   - 見出し右側の **`[➕ 観光地追加]` `[➕ グルメ追加]` `[➕ 地酒追加]`** や各行の **`[✏️]`** から、新しいスポットや口コミを直接登録可能。

3. **📜 和紙風ライトモード ＆ 日本の伝統色パレット**:
   - 生成り（鳥の子紙色）の背景と和紙テクスチャ。
   - 6地区を日本の伝統色（水浅葱・撫子桜・若草・藤・山吹・青緑）で優雅に色分け。

4. **📝 全漢字ふりがな（ルビ）表示 ＆ 送り仮名・カタカナ完全分離**:
   - 難読地名や名所・郷土料理を含むすべての漢字に正確なふりがな（ルビ）を付与。

5. **⚡ GitHub 完結型 全自動ビルド＆デプロイ（GitHub Actions）**:
   - `patamap_data.json` を編集して保存（コミット）するだけで、GitHub Actions が自動でマップを再ビルドし、約15秒で本番サイトが最新化されます。

## 📝 データの追加・編集方法（ブラウザだけで完結！）

管理者やフロリさんは、パソコンに専門ソフトがなくても **GitHub の Web画面上だけで直接データを追加・編集できます**。

1. GitHub リポジトリの **[`patamap_data.json`](patamap_data.json)** をブラウザで開きます。
2. 右上の **鉛筆アイコン（Edit this file）** をクリックします。
3. 該当する都道府県の `観光地`、`食べ物`、`お酒`、または `メモ` に項目を追記・修正します：
   ```json
   "茨城県": {
     "地区": "関東",
     "観光地": "国営ひたち海浜公園、偕楽園（梅林）、袋田の滝...",
     "食べ物": "水戸納豆、あんこう鍋...",
     "お酒": "来福、森嶋...",
     "メモ": "国営ひたち海浜公園: ネモフィラは4月下旬が見頃！、大洗磯前神社: 神磯の鳥居の日の出は絶景！"
   }
   ```
4. 右上の緑色の **「Commit changes...」** ボタンを押して保存します。
5. ➜ **GitHub Actions が自動でビルドを開始し、約15秒後に本番サイト（GitHub Pages）が自動更新されます！** 🎉

## 💻 ローカル開発・手動生成

### 1. 依存ライブラリのインストール
```bash
pip install -r requirements.txt
```

### 2. マップHTMLの生成
```bash
python patamap.py
```
実行すると、`patamap_data.json` と `japan.geojson` を読み込んでスタンドアロンな `index.html` が生成され、ブラウザで自動起動します。

## 📁 ディレクトリ構成

- `patamap.py`: Web地図HTML自動生成メインスクリプト
- `index.html`: 生成されたWeb地図ページ（スタンドアロン公開用）
- `patamap_data.json`: 47都道府県のマスターデータ（観光地・グルメ・お酒・メモ）
- `japan.geojson`: 日本地図の行政区域境界データ（GeoJSON）
- `.github/workflows/pages.yml`: GitHub Actions 自動ビルド＆デプロイワークフロー
- `requirements.txt`: 依存ライブラリ一覧
