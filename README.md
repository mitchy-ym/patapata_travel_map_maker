# 「リスナーと作る！全国観光マップ（フロリの47都道府県パタパタ旅行企画）」生成スクリプト

## 1. 概要
本リポジトリは、表計算ファイル（Microsoft Excel形式）に記録された日本国内47都道府県の観光・地域資源データを抽出し、地理情報データ（GeoJSON）と統合してWebブラウザ上で閲覧可能な対話型地図「リスナーと作る！全国観光マップ（フロリの47都道府県パタパタ旅行企画）」（HTML/JavaScript形式）を自動生成するPythonスクリプトおよび関連成果物を管理するものである。

## 2. システム仕様

### 2.1 動作環境
- **実行基盤**: Python 3.10 以上
- **主要依存ライブラリ**:
  - `pandas`: 表形式データの解析および構造化
  - `openpyxl`: Excel（.xlsx）ファイルの入出力
  - `requests`: 地理情報データ取得時のHTTP通信
- **描画エンジン**: Apache ECharts 5.4.3（CDN経由でロード）

### 2.2 データ入出力仕様
- **入力データ**:
  - `original/*.xlsx`（またはプロジェクトルートのExcelファイル）: 都道府県別の観光資源、食品、酒類等の記録データ（※非公開データのためリポジトリ管理対象外）
  - `japan.geojson`: 日本国内47都道府県の境界座標データ（WGS84測地系、軽量化処理済み）
- **中間成果物**:
  - `patamap_data.json`: 抽出・正規化された都道府県別属性データ（UTF-8形式）
- **最終出力物**:
  - `index.html`: 単一ファイルで動作するスタンドアロン型静的Webページ

## 3. ディレクトリ構成
```
.
├── .github/workflows/
│   └── pages.yml           # GitHub Pages 自動配信ワークフロー定義
├── index.html              # 生成されたWeb地図ファイル（公開対象）
├── patamap_data.json       # 抽出済み構造化データ
├── japan.geojson           # 都道府県境界データ
├── patamap.py              # データ抽出・HTML生成スクリプト
├── requirements.txt        # 依存ライブラリ一覧
├── .gitignore              # Git管理除外設定（Excelファイル等を除外）
└── README.md               # 本仕様書
```

## 4. 運用手順

### 4.1 環境構築
以下のコマンドを実行し、所定の依存パッケージをインストールする。
```bash
pip install -r requirements.txt
```

### 4.2 データ抽出およびWebページの生成
以下のスクリプトを実行することで、入力データの読み込み、名称正規化、JSON変換、および `index.html` の再構築が一括処理される。
```bash
python patamap.py
```

### 4.3 配信環境への反映
生成されたファイルをリポジトリの `main` ブランチへコミットおよびプッシュすることにより、CI/CDパイプラインを介して公開環境（GitHub Pages）へ自動配信される。
```bash
git commit -am "Update data"
git push origin main
```

## 5. 留意事項
- 本システムにおける地域区分、表示色、初期表示座標等のパラメータは `patamap.py` 内の定数定義領域にて管理されている。
- データの更新時は、入力元ファイルの列構成および都道府県名の表記揺れに留意すること。
