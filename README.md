# 🗾「リスナーと作る！全国観光マップ（フロリの47都道府県パタパタ旅行企画）」

47都道府県の観光地・ご当地グルメ・お酒データをインタラクティブに閲覧・探索できるWeb地図（`index.html`）の自動生成ツールです。

## 🌟 主な機能と特徴

1. **🗺️ / 🔍 デュアルアクション連携（全47都道府県）**:
   - **📸 観光地・名所**: すべてのスポットに `[🗺️ Googleマップ]` と `[🔍 Google検索]` の両方のアクションボタンを搭載。
   - **🍽️ ご当地グルメ・食べ物**: 特定の店舗・施設・市場が存在する名物には `[🗺️]` と `[🔍]` の両方を、一般的な郷土料理には `[🔍]` を最適配置。
   - リンククリック時に「世界遺産・国宝」「特別名勝」などの修飾フレーズを自動トリミングし、ピンポイントな検索精度を実現。

2. **📝 全漢字ふりがな（ルビ）表示 ＆ 送り仮名・カタカナ完全分離**:
   - 難読地名や名所・郷土料理を含む**すべての漢字**に正確なふりがな（ルビ）を付与。
   - 送り仮名（例: `炭焼き` ➜ `炭焼` + `き`）、カタカナ、英数字、記号を `<ruby>` の外に100%厳密に分離し、文字重なりのない美しい表示を実現。

3. **🎨 Google Fonts「Noto Sans JP」採用**:
   - 美しいモダンな日本語タイポグラフィと垂直センタリングされたルビデザイン。

4. **🎯 直感的なインタラクティブ操作**:
   - **地区別カラー色分け ＆ 拡大ボタン**: 6つの地方エリア（北海道+東北、関東、中部、関西、中国+四国、九州+沖縄）をクリック一発で拡大表示。
   - **都道府県プルダウン選択**: 都道府県を選択すると、該当地域へ自動ズーム ＆ ポップアップカードを自動表示。
   - **ホバー・クリック連動**: 地図上の都道府県にマウスを乗せるだけで詳細カードが表示され、クリックでも固定表示。

5. **📜 枠内完結カスタムスクロールバー ＆ レスポンシブ対応**:
   - 角丸カードの枠線内に美しく収まるスリムなカスタムスクロールバー。
   - スマートフォンやタブレット（幅640px以下）でも快適に操作可能。

## 🚀 使い方

### 1. 依存ライブラリのインストール
```bash
pip install -r requirements.txt
```

### 2. マップHTMLの生成
```bash
python patamap.py
```
実行すると、`patamap_data.json` と `japan.geojson` を読み込んでスタンドアロンな `index.html` が生成され、デフォルトブラウザで自動表示されます。

### 3. Webサイトの公開・更新（GitHub Pages）
```bash
git add .
git commit -m "Update map data and UI improvements"
git push origin main
```

## 📁 ディレクトリ構成

- `patamap.py`: Web地図HTML自動生成メインスクリプト
- `index.html`: 生成されたWeb地図ページ（スタンドアロン公開用）
- `patamap_data.json`: 47都道府県の全漢字ルビ付きマスターデータ
- `japan.geojson`: 日本地図の行政区域境界データ（GeoJSON）
- `requirements.txt`: 依存ライブラリ一覧（pandas, openpyxl, requests, pykakasi）
- `original/`: 元データ（Excelファイル等）
